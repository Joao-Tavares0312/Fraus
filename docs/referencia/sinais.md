# Os sinais

As oito famílias que leem a conversa. Todas leem **apenas a fala do cliente**
(`mensagens_cliente`) — e isso não é detalhe de implementação, é a fronteira que
mantém o sistema fora da proibição de reconhecimento de emoção no local de
trabalho. Ver [Conformidade](../conformidade.md).
